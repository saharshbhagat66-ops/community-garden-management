## Problem Statement
Shared gardens need to coordinate plots, volunteers, schedules, and maintenance responsibilities.

## Project Objective
Build a responsive, user-friendly management platform for community garden operations using HTML5, CSS3, and Vanilla JavaScript with persistent `localStorage`.

## Core Features Implemented
1. **Admin Dashboard:** Real-time KPIs (plot occupancy, member count, pending tasks, total harvest in kg, volunteer hours), visual breakdown charts, and JSON data export.
2. **Garden / Plot Management:** Add plots, filter by status (`Occupied`, `Available`, `Maintenance`), and update status in one click.
3. **Member Registration:** Register gardeners, volunteers, and coordinators with live search and directory management.
4. **Task Scheduling:** Schedule garden chores with priority tags, due dates, status filters, and completion toggles.
5. **Watering & Maintenance Logs:** Record watering, weeding, composting, pruning, and pest control logs.
6. **Harvest Records:** Track produce weight (kg), distribution channels, and automatic harvest totals.
7. **Volunteer Hours:** Log volunteer shifts with automatic leaderboard rankings on the dashboard.
8. **Announcements:** Post categorized community notices (`Event`, `Maintenance`, `Alert`, `General`).

## Tech Stack
- **HTML5** (Semantic structure & forms)
- **CSS3** (Flexbox, CSS Grid, responsive sidebar, CSS custom properties)
- **JavaScript (ES6+)** (DOM manipulation, state management, `localStorage` persistence)

## How to Run Locally
Simply open `index.html` in any modern web browser — no build step or server required.
